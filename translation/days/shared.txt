# Shared — the day-independent events (PLAN TRN-03 pilot, extended after review).
# Every event with no day in its id (E00xx, E4xxx, E5xxx, E8xxx) that (a) sits in a map variant the
# game loads on August 1 (EVVER.BIN, research/event-scripts.md § "Map names"), (b) has an entry
# condition day 1 can satisfy, and (c) is placed where the day-1 flow can walk, from 15:30, when
# E0185 sets the clock, to bedtime — plus the day-independent events the later day files found
# missing (E0006/E0007, E8054, E4038/E4039, E8063, E4026), which belong here so that each event is
# translated once (translation/days/README.md), and the nine `boku coverage` found nobody had been
# asked for (E1006, E8014, E4019, E4020, E8059-E8061, E8064, E8065). E1605 carries a day-16 id but
# its condition (day > 0) and placement (H10, every variant, every slot) make it day-independent, so
# it is here too.
#
# Whether the day-1 flow can leave the grounds is UNTESTED. The house and grounds are the G and H
# bases (bible § 7); the first version of this file excluded the outdoors (A–E) on three grounds
# the reviewer showed to be weak: no A–E base has an evening map (true, but day 1's free time is
# an afternoon, 15:30–18:00, and the A bases all have a slot-1 map); E0185 forbids the mountains
# (a spoken rule — the only zone block on an H base is E0002, hour >= 19); and the walkthroughs put
# the first thing outside the gate on August 2 (jooey's 8/2 list also carries the workshop shelf,
# which this file has for day 1, so his placement is "from now on", not first availability).
# What the data does say: E8027 ("It's locked.") sits on H02 in every variant, so the front gate is
# never an exit, and the ways out are H04's back gate (E8028 locks it only at night) and H16, the
# path (E0002, night); no event is gated day == 1 except the voice-only uncle/Shirabe chats inside
# the grounds (E5004/06/08/10, E5041); E0254 (A17) and E0206 (A16) carry day > 1 / day >= 2 guards
# that only make sense if the outdoors can be walked on day 1. Against that, EVVER loads two
# day-1-only afternoon variants, H04101 and H08103, whose placement tables are identical to
# H04100 / H08100 — a geometry or prop difference the data cannot read, and the crux. Only play
# decides it: stand at H04's gate and on H16 at 16:00 on day 1. Until then the nearest A-base
# one-liners are translated below and their headers say "any day the outdoors is walkable".
#
# Format: translation/days/README.md; policies: style-guide.md, glossary.md, bible.md. day01.txt
# already holds E0001, the other day-independent event of the day.
#
