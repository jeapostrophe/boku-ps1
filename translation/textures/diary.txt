# The picture diary (PLAN GFX-04): Boku's entry on each page, keyed by page id, not by day --
# the game picks a page for each day at run time (g_diary_pages), and a page can serve more
# than one day. Format: translation/textures/README.md. Style: translation/style-guide.md
# section 14 -- a third-grader's sentences, short and declarative, correctly spelled.
#
# Each entry is set in the game's own glyphs on five ruled lines of about 32 characters;
# the build refuses an entry that does not fit rather than shortening it. The date strip
# at the right of the page stays as it is (Jay, 2026-09-21). NIKKI_000 is the unused dummy
# page and takes no entry. Translated in the TRN-04 maximal session (2026-09-24) from the
# page images, each with the scene that proposes the page, and reviewed against the Japanese.
# Pages 072-099 are the generic pool (a day when nothing happened) and carry one text.

# --- NIKKI_001: day 1, Mom's baby and staying at Uncle's
# NOTE NIKKI_001: "isoro" is "freeloader" by glossary 3, which names this page; the style guide 14 sample ("I'm staying at Uncle's house") predates that entry.
nikki@NIKKI_001	Mom is having a baby, so it's a big fuss! I'm a freeloader at Uncle's house. I wonder if there will be lots of fun things?
# --- NIKKI_002: generic, bugs are faster than me
# NOTE NIKKI_002: the page writes the bugs as a doubled "mushi-mushi", Boku's child word for bugs (again on NIKKI_010); rendered plain "bugs".
nikki@NIKKI_002	Bugs are fast. I am slow. I only have 2 legs. Those guys have lots. I lose.
